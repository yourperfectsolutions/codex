# NeoSpark

NeoSpark is the AI-driven operational system for Your Perfect Solutions (YPS). This prototype demonstrates the initial branding and user interface based on the provided style guide.

## Structure
- `index.html` – main web page
- `styles.css` – theme and component styles

## Usage
Open `index.html` in your browser to view the demo page.

Fonts **Univa Nova** and **Ethos Nova** are referenced but may fall back to system fonts if not installed.
